# XQ32 syntax lowering

Implementation: `Xq32LowLevelCodeUnitConverter`.

XQ32 is the later Level5 compiler (after the XSEQ → XQ32 format switch). Round-trip gold: `prog_common` (XQ32 binary).

Related: [xseq.md](xseq.md) (older compiler), [gss1.md](gss1.md) (currently a copy of XSEQ).

---

## Control flow

Numeric jump labels are `@000@`, `@001@`, … (at least three digits). Existing labels in the source are never reused.

`true` in a condition becomes the integer `1`.

### If-then

Skip the body when the condition is false (`IfNotGoto`). Empty `else { }` is emitted as if-then (ELSE/JOIN can share an instruction after jump-table sort).

High-level:

```
if sub5600($local0, $param4) {
    sub5252($local0);
}
```

Low-level:

```
	$temp1 = sub5600($local0, $param4);
	if not $temp1 goto "@000@";
	$temp1 = sub5252($local0);
"@000@":
```

### If-else and `else if`

`IfNotGoto` ELSE, then-body, `goto` JOIN, ELSE, else-body, JOIN.

The **JOIN label is allocated before the then-body**, so nested if/while labels are numbered after ELSE and JOIN (`if { while } else` → else `@000@`, join `@001@`, while `@002@`).

High-level:

```
if not sub5009($param0) {
    $local0 = sub5002($param0, $param1, $param2, $param3, 0);
} else {
    $local0 = sub522($param0);
}
```

Low-level:

```
	$temp1 = sub5009($param0);
	if $temp1 goto "@000@";
	$local0 = sub5002($param0, $param1, $param2, $param3, 0);
	goto "@001@";
"@000@":
	$local0 = sub522($param0);
"@001@":
```

A single nested `if` in the else arm is `else if` when raising; lowering still emits a full if-else chain.

### If with `return` / `goto` in the then arm

Dest 1 is reused for the next if at the join. (XQ32 does **not** bump the next if to dest 2.)

High-level:

```
if $param4 != sub15298() {
    return 0;
}
if $param5 >= 0 {
    ...
}
```

Low-level (next if still `$temp1`):

```
	$temp1 = sub15298();
	$temp1 = $param4 != $temp1;
	if not $temp1 goto "@001@";
	return 0;
"@000@":
"@001@":
	$temp1 = $param5 >= 0;
	if not $temp1 goto "@002@";
```

### Jump polarity (no extra `not` instruction)

Polarity is only the jump opcode. Unary `not` on a condition is folded:

| High-level skip | Low-level |
|---|---|
| `if x { … }` | `if not x goto ELSE` |
| `if not x { … }` | `if x goto ELSE` |
| `while (x);` | `L: if x goto L` |
| `while (not x);` | `L: if not x goto L` |

High-level:

```
if not $local9 {
    return 0;
}
```

Low-level:

```
	if $local9 goto "@000@";
	return 0;
"@000@":
```

High-level:

```
while (not sub2110(27102));
```

Low-level:

```
"@000@":
	$temp1 = sub2110(27102);
	if not $temp1 goto "@000@";
```

A real `not` in a value (then used in `and`/`or`, not only as jump polarity) still emits a NOT instruction.

### Empty / one-line `while`

Spin: label, then `IfGoto` of the condition on **dest 1**.

High-level:

```
while (sub13690(4));
```

Low-level:

```
"@000@":
	$temp1 = sub13690(4);
	if $temp1 goto "@000@";
```

### `while` with a body

Head, `IfNotGoto` exit (dest 1), body, `goto` head, exit.

High-level:

```
while (true) {
    $local1 = sub13760($param0, $local0);
    if $local1 == "" {
        break;
    }
    ...
}
```

Low-level:

```
"@005@":
	if not 1 goto "@006@";
	$local1 = sub13760($param0, $local0);
	$temp1 = $local1 == "";
	if not $temp1 goto "@007@";
	goto "@006@";
"@007@":
	...
	goto "@005@";
"@006@":
```

### `do { } while (cond)`

Head, body, continue latch, `IfGoto` head (dest 1), exit.

### `for`

Initializer (if any), head, `IfNotGoto` exit, body, optional continue latch, iterator, `goto` head, exit.

A distinct continue latch is allocated **only** if the body contains `continue` (otherwise the latch would be an unreferenced label after re-raise). Nested loops do not count as using this loop’s `continue`.

### `break` / `continue`

`goto` the current loop’s exit or continue label. Invalid outside a loop.

Unstructured `if goto` / `if not goto` in the source is flattened in place (IfGoto dest 1, IfNotGoto dest 1).

## `$temp` allocation

Slots that still appear as `$tempN` in the high-level source are skipped (`TempSlotFrame`). After folding, that set is usually empty.

### Result dests

| Construct | Dest |
|---|---|
| Discarded call / return value / `IfNotGoto` / `IfGoto` | `$temp1` |
| Named `$local` / `$global` / `$param` / `$ctx` assign | dest 0 (children from `$temp1`) |
| Postfix `++` / `--` statement | dest 0 |

Discarded calls **do not** keep dest 1 reserved for the next statement; the next packed expression may reuse `$temp1`.

### Calls: pack only complex arguments

Argument `i` does **not** occupy `$temp{dest+i+1}`. Only complex operands take the next free slot starting at the call’s result dest (usually 1). Leaves (`$param`, literals) take no temp.

High-level:

```
sub5430($param0, $param1, $local0 >> 1, $local1 >> 1);
```

Low-level:

```
	$temp1 = $local0 >> 1;
	$temp2 = $local1 >> 1;
	$temp1 = sub5430($param0, $param1, $temp1, $temp2);
```

High-level:

```
Common_MsgObjSetup_Ex3(..., $param6 - 1, ...);
```

Low-level:

```
	$temp1 = $param6 - 1;
	$temp1 = Common_MsgObjSetup_Ex3(..., $temp1, ...);
```

Nested call as an argument reuses dest 1:

```
sub6242(sub522($local15), $local2, $local3, $local4);
```

```
	$temp1 = sub522($local15);
	$temp1 = sub6242($temp1, $local2, $local3, $local4);
```

### Binaries and logicals: pack from the result dest

Complex operands get sequential temps starting at the result dest. Leaves do not take a hole.

High-level:

```
if $param4 != sub15298() {
```

Low-level:

```
	$temp1 = sub15298();
	$temp1 = $param4 != $temp1;
	if not $temp1 goto ...
```

High-level:

```
if sub14807($local0) or sub14822($local0) or sub14823($local0) {
```

Low-level:

```
	$temp1 = sub14807($local0);
	$temp2 = sub14822($local0);
	$temp1 = $temp1 or $temp2;
	$temp2 = sub14823($local0);
	$temp1 = $temp1 or $temp2;
	if not $temp1 goto ...
```

High-level:

```
if $param0 == 5 or $param0 == 15 {
```

Low-level (string/`==` `and`/`or` is **not** forced to dest 2):

```
	$temp1 = $param0 == 5;
	$temp2 = $param0 == 15;
	$temp1 = $temp1 or $temp2;
	if not $temp1 goto ...
```

Named dest `$local = $a == $b` with both leaves emits no temps.

### Unary `not` / casts (when not folded into a jump)

Child dest equals the result dest when dest ≥ 1.

High-level:

```
$temp1 = not sub1200();
```

Low-level:

```
	$temp1 = sub1200();
	$temp1 = not $temp1;
```

### Array indexes

Complex indexes pack like call arguments (sequential from dest). Array **stores** with a complex RHS spill to a temp first so indexes are not stolen:

```
	$temp1 = <rhs>;
	$a[i] = $temp1;
```

Compound assigns (`+=`, …) always spill a value RHS.

### Chain assignment

Only `=` chains. Inner assign first, then copy via dest 1:

```
$local3 = $local2 = sub604($local0 * 6f);
```

```
	$temp1 = $local0 * 6f;
	$temp1 = sub604($temp1);
	$local2 = $temp1;
	$local3 = $local2;
```

### Switch expression

The switched value spills at the result dest (XQ32) then the switch instruction writes dest.

### `yield` / `exit` / `return`

Pass through. `return <expr>` evaluates `<expr>` into `$temp1`.
